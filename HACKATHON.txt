Indie Developer Track / Build for Your World

The OurTake React studio and Node editing pipeline were developed during the hackathon. Existing packages and third-party footage are credited separately and are not claimed as original contributions.

The demo video uses Muse Spark 1.3 Contributor and Muse Voice Transcribe 1.0 through Meta Model API. It shows saved results from actual API runs, not live inference timing. The visual-story example uses three silent excerpts from one Cinestudy festival recording; it is not an independent multicamera dataset. Festival source files are not bundled in this repository. The footage source and credits are recorded in DEMO_EVIDENCE.json.

The bundled beach example is a separate, curated CC0 montage with preset sample-mode edits. Its credits are in public/demo/credits.html.

See README.md for setup, provider configuration and prototype limitations.
